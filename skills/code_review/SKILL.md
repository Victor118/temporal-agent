# Code Review Skill

## Instructions
When reviewing code:
- Check for error handling completeness
- Verify input validation at system boundaries
- Look for potential security issues (injection, XSS, etc.)
- Ensure tests cover the changes
- Check for performance concerns (N+1 queries, unbounded allocations)
- Verify naming conventions and code style consistency
- Flag any hardcoded secrets or credentials
